# PrankFX Development Instructions

## Project
PrankFX is a mobile application.

Frontend:
- Expo 54
- React Native
- TypeScript
- Expo Router

Backend:
- FastAPI
- Python
- MongoDB
- Motor
- JWT authentication

## Structure

frontend/
backend/

## Rules

Before making changes:
1. Inspect the existing implementation.
2. Do not rewrite working functionality unnecessarily.
3. Preserve the existing architecture.
4. Check related files before changing code.
5. After changes, run appropriate TypeScript/Python checks.
6. Fix errors instead of stopping after identifying them.
7. Do not create duplicate components or duplicate functionality.
8. Keep existing API contracts unless there is a good reason to change them.
9. Check frontend and backend compatibility after API changes.

## Important

Work autonomously when possible.
Do not stop after finding an error.
Investigate the cause, implement the fix, and test it.

Before finishing:
- check TypeScript errors
- check backend errors
- check imports
- check API endpoints
- check authentication
- check navigation
- check localization
- check that existing functionality was not broken

When something is unclear, inspect the project first before asking me.
